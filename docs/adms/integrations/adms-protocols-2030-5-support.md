## Summary
ADMS supports the 2030.5 protocol via the FEP server, implemented per the 2030.5.1 standard.

## Content

### Overview
- **Protocol**: 2030.5
- **Support Location**: FEP (Front-End Processor) server in ADMS (Advanced Distribution Management System)
- **Implementation Basis**: 2030.5.1 standard documentation

### Key Details
- Enables communication using 2030.5 protocol specifications.
- No additional configuration required beyond standard FEP server setup.
- Compatible with ADMS environments adhering to 2030.5.1 guidelines.

For configuration or troubleshooting, refer to ADMS FEP server documentation.
